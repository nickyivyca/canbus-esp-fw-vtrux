# shared/twai_port/test_app/test/

Host tests of the probe's no-acknowledge modes, m1-m3, of its register
files, and of the T19 app's command line and switch commands
(`../../SPEC.md` T13, T14, T17, T19; the
implementor's, as the probe is, T11). Self-checks, not verification: the
tester measures on the bench.

    make -C shared/twai_port/test_app/test run      # from the repo root; `asan` for the sanitiser build
    python3 shared/twai_port/test_app/test/mutate.py [--only N,N...]

The binaries go to `scratch/twai_port-probe-test/` at the worktree's root.

| File | What |
|---|---|
| `test_unacked.c` | `twai_port_unacked.c` against a script: the register layer and the target calls are given by a timeline of unacknowledged attempts (TS = 1 for the attempt, TS = 0 for the idle, the TEC up 8 at each attempt's end until 128) and a rule for what an abort does (remove the frame if issued with TS = 0, or nothing). The clock moves only when the code reads it; in the hold the CPU cycle counter runs for only a twentieth of the time `esp_timer` does, as on the C3, where it stops while the CPU idles. Cases: the arguments and every refusal; m1's trace (every change and only changes, timed within a sample, the TEC with each, attempts counted, the first sample kept), TS stuck at 1, TEC-only changes, a frame that completes, a stall counted and flagged, the trail, the 2048 records running out; m2 in the error-active and the error-passive idle, by attempt and by time, TS never 0, freed before the abort, an abort with no effect; m3 by attempt and by time, delay 0, a delay that lands in the idle; `fresh`, the skips, `irq=off`, the unsupported chip; the hold (`hold_ms`; the script can bring back an acknowledging node at its start): after the trace's reads and before the cleanup and the settle, nothing sampled, recorded or aborted in it, interrupts on, its length (in `esp_timer` time) and its end read, the clock check over the trace only, none for a skipped trial, run also when the trace saw the buffer free, m1's frame going out in it, an aborted frame not going out, a frame the abort left going out, the cleanup after it when no node returns; the answer, its ns times, its nulls, the stack margin at its end and a failed chunk |
| `test_probe_ll.c` | the C3 register file against `mock/` (each status bit, the TEC, the abort's two modes, the reads before and after the command, the command inside the critical section); the same cases for the S3 file (T19), built with `-DCHIP='"s3"'`; and, built with `-DPROBE_LL_UNSUPPORTED`, the unsupported file (refuses, touches nothing) |
| `mock/` | host stand-ins for ESP-IDF v5.4.2's esp32c3 `hal/twai_ll.h` (the status and TEC the case sets, the abort command counted; the esp32s3 header has the same calls and status bits) and `freertos/FreeRTOS.h` (the critical section counted); and, compile only, for `test_stack.py`: `freertos/task.h`, `driver/twai.h`, `esp_err.h`, `esp_log.h` (the log macros as a variadic call), `esp_timer.h`, `esp_app_desc.h`, `esp_http_server.h` and shared/can_port's `can.h`, the declarations the URI handler and the run use |
| `test_t19_parse.c` | the T19 app's command line (`twai_port_t19_parse.c`): the split, the refusals (empty, too long, not key=value, empty key, too many arguments), found, absent and unusable arguments and the first of two, a key a command does not take, whole numbers in range, JSON strings escaped and refused when they do not fit |
| `test_t19.c` | the T19 app's switch commands (`twai_port_t19.c`), the app whole with shared/can_port's real dispatch (`can_port.c`), over a fake port: the stock calls as `can_stock.c` has them (`can_set_silent()` ignored while the bus is on) and a kept-driver switch that makes one report per change (seq, mode, REC 128 into listen-only and 0 out of it) and hands queued frames to the T17 hook. Cases: `switch to=lom` and `to=normal` each reach the switch, by one set-mode call, and answer the call's return and the port's mode; `n=3` frames reach the hook once each, in order, with their tags, and are counted; `switchloop` makes real switches by turns and puts an odd `k` back to normal; from listen-only it starts in normal; a refused call answers its error, and a call that ran no switch is zeros with its return as the result. Every switch case fails on the app at tag 2026.11.27.6, which switched through `can_set_silent()` (T19 run `bench_t19_1d4221c9`). The other commands run only on the S3 |
| `mock_t19/` | for `test_t19.c` only, ahead of `../../unit/mock/` and `mock/`: `esp_system.h` (the restart calls, and `stdlib.h`), `esp_idf_version.h`, `freertos/task.h` and `driver/twai.h` (the unit mock's, by `#include_next`, with the task-create call and `TWAI_ALERT_ALL`) |
| `test_stack.py` | the probe's stack use on the host, from gcc's `-fcallgraph-info=su` of the URI handler (`twai_port_txabort_http.c`), the run (`twai_port_txabort_probe.c`) and `twai_port_unacked.c`: every frame at most 768 bytes and bounded; the deepest call path from the handler at most 1536 bytes; and m1-m3's path, without the older phases, at most 1024. These are budgets, not measurements of the C3. The probe runs on the httpd task's 5120-byte stack. Twice its buffers on the stack overflowed it (gen-inhibit `VERIFICATION.md` 12.4): at shared/main 3bb6c945 the answer's (every m1-m3 call panicked, 2026-11-28), and at 9d1dc134 the handler's and the run's (`stack_free_min` 44-108 bytes, 10 of 140 calls restarted, 2026-11-27). The check fails on both commits |
| `Makefile` | the six binaries: `test_unacked`, `test_probe_ll_c3`, `test_probe_ll_s3`, `test_probe_ll_unsupported`, `test_t19_parse`, `test_t19`; and `stack_http.ci`, `stack_probe.ci` and `stack_unacked.ci` for `test_stack.py`, which `run` runs last (`PYTHON=` names the Python) |
| `mutate.py` | the mutants: each breaks one behaviour of `twai_port_unacked.c`, a register file, the T19 command line, the T19 app's switch commands, or the stack use of the URI handler or the run, in a copy (of `test_app/` and the files `test_t19` builds against outside it), and the run passes only if the unmutated build passes and every mutant builds and fails (`test_stack.py` included); a mutant that does not build, or whose text does not occur once, fails the run. Its copies go in its own folder under `scratch/twai_port-probe-mutants/`, removed when it ends |
