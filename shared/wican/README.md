# shared/wican/

The stock WiCAN code, as one ESP-IDF component, `vtrux/wican`, which a
project takes at a pinned tag (port plan goal 18, `SPEC.md` W1). It comes
from gen-inhibit's tree at port step 1a.

| File | What |
|---|---|
| `SPEC.md` | The component's spec, W1 to W11. |
| `VALIDATION.md` | Why each requirement is written as it is. |

The code is not here yet; it arrives with gen-inhibit's step 1a, and this
file then records who owns each file (`SPEC.md` W11). `VERIFICATION.md` is
the tester's, written when there is code to test.

The spec and `VALIDATION.md` belong to the reviewers: a change is drafted by
the reviewer of the project that needs it and ruled by the user in that
reviewer's session.
